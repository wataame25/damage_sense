damage_sense

環境：ブラウザまたはアプリ

出題ルール
攻撃側のポケモンと防御側のポケモンを出題、この時攻撃側のポケモンの技選択防御側に最もダメージを出すことができる技を選択。

難易度選択
簡単：４択の中から正解を選択させるモード。次の問題に進むかやめるかを毎問題解答後に選択可能
普通：最低乱数の値を入力し誤差5%までを正解とするモード。次の問題に進むかやめるかを毎問題解答後に選択可能。回答として、最低乱数〜最高乱数までの値を出力
チャレンジ：最低乱数の値を入力。誤差のパーセントを記録。全10問を出題し、誤差の合計の少なさを測定。
最低乱数の値が100を超える場合は100を入力する。最低乱数が110を超える問題はそもそも出題しない。

ファイル構成（AIと相談したい）
・現状の上位50ポケモン、５種の技、及び持ち物のデータ、持ち物は上位10%を超える最大5種を格納
・技一覧　技名とタイプと、追加効果
・ポケモン一覧　ポケモン名単位のテーブル、タイプ、特性（3つまで）技5つまで、種族値のデータ
・特性一覧　攻撃や防御に関連する、持久力は特に注意
・もちもの一覧　ポケモンの技の倍率を変更するものだけに絞り込み、1.1倍系、1.2倍系、1.3倍系
・mainの実行ファイル（諸々の計算式あり、ここで努力値も振る、ここで振られた努力値は出題の際に開示する）

その他ルール　一旦使用率系はスナップショットで作成。いつ時点のデータかわかるようにする。
・使用率上位50位のポケモンかつ技使用率上位5種(攻撃技に絞り込む)いずれかを使用
・使用率上位50種に「りゅうのまい」「つるぎのまい」「わるだくみ」「ちょうのまい」といった攻撃力を強化する技が入っている場合はランダムで1回使用した状態で問題を出題しても良い。
・もちものについては、メガストーンの所持率が60%を超える場合にはメガポケモンとして出題、30%超える場合はメガなしとメガありランダムで出題。もちろんナイト（メガ進化のためのアイテム）を持っている場合は他のアイテムは所持できない
・守備的なポケモンは攻撃側に選出しない（アーマーガァやドヒドイデ、ピクシー）
・火力アップのもちものの所持率が10%を超えている場合にランダムでその持ち物を持った状態で出題。火力アップの計算を行うようにする。

事前準備
・上位50位のポケモン及び技使用率上位5種、もちもの上位5種についてはポケモンバトルデータベースのシングルランキングを使用。https://champs.pokedb.tokyo/pokemon/list?rule=0
・全ポケモン一覧のテーブルを作成。https://yakkun.com/ch/zukan/
・技一覧についてはポケモン徹底攻略を使用。https://yakkun.com/ch/move_list.htm
・特性一覧についてはポケモン徹底攻略を使用。https://yakkun.com/ch/ability_list.htm
・もちもの一覧についてはポケモン徹底攻略を使用。https://yakkun.com/ch/item.htm

mainファイル内で実装したいもの
・攻撃側、防御側のポケモンを選定
・特性（攻撃側及び防御側の特性を考慮）
・天候（砂や雪は防御側に好影響、晴れや雨は攻撃側の技威力に好影響）
・フィールド（フィールドの恩恵を受けるポケモン、受ける技を判定）
・攻撃側が選択する技を選択
・計算（最低乱数が110を超える場合は再作成）

懸念事項
・メガ進化して使用する技が全く異なるようなポケモンの扱いに苦慮しています。
例：メガリザYはソーラービームを打ちますがメガリザXは打たない。通常ガブリアスは物理型のポケモンだが、メガガブリアスZは特殊型のポケモン
→上記懸念事項について、リザードンはメガリザードンYであることが多いため特殊型のメガリザYのみを出題、ガブリスはメガしない型が多いので通常のガブリアスとして出題を固定させてください。

遊び方
・ブラウザ版：docs/index.html をブラウザで開く（このファイル1つで動く。データも埋め込み済み）
・ターミナル版：python3 main.py --mode easy（normal / challenge）
・データやコードを変更したら python3 build_web.py で docs/index.html を作り直す

公開方法（GitHub Pages）
1. GitHubで新しいリポジトリを作成する（例：damage_sense）。README等の初期ファイルは作らない
2. このフォルダでリモートを登録してpushする
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin poke_damage
   ※パスワードの代わりにGitHubの Personal Access Token（Settings → Developer settings → Tokens）を入力する
3. リポジトリの Settings → Pages → Build and deployment で
   Source：Deploy from a branch、Branch：poke_damage、フォルダ：/docs を選んで Save
4. 数分後に https://<ユーザー名>.github.io/<リポジトリ名>/ で遊べるようになる
5. 以降の更新は python3 build_web.py → git commit → git push で自動的に反映される
