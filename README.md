# ダメージ感覚（damage_sense）

ポケモンの対戦で「この技でどれくらい削れるか」を感覚で掴むためのトレーニングゲームです。
実際の対戦でよく使われているポケモン・技・持ち物・性格・能力ポイントの組み合わせで出題されるので、
遊ぶほど実戦のダメージ感覚が身につきます。

**▶ 遊ぶ：https://wataame25.github.io/damage_sense/**

インストールやログインは不要です。パソコンでもスマホでも、ブラウザで開くだけで遊べます（スマホでは攻撃側・技・防御側が1画面に収まるレイアウトになります）。

---

## どんなゲーム？

画面に攻撃側と防御側のポケモン、使う技、天候やフィールドが表示されます。
その技で **防御側のHPを何％削れるか** を答えてください。

出題画面には、計算に必要な情報がすべて表示されます。

- 攻撃側：特性・持ち物・性格・能力ポイントの振り方・こうげき（とくこう）の実数値
- 防御側：特性・性格・能力ポイントの振り方・HPとぼうぎょ（とくぼう）の実数値
- 使う技（攻撃側の技のうち、その相手に一番ダメージが出る技が自動で選ばれます）。タイプ一致のときは「タイプ一致 ×1.5」と表示されます（てきおうりょくは×2、リベロ・へんげんじざいで一致になる場合はその旨も表示）
- 天候・フィールド

## 3つのモード

| モード | 答え方 | 正解の条件 |
|---|---|---|
| **簡単** | 4つの「最低〜最高ダメージ％」から選ぶ | 正しい範囲を選ぶ |
| **普通** | 最低乱数のダメージ％を数字で入力 | 正解との差が±5％以内 |
| **チャレンジ** | 最低乱数のダメージ％を数字で入力（全10問） | 10問の誤差の合計が小さいほど高成績 |

- 簡単・普通は1問ごとに「次の問題」か「やめる」を選べます。やめると成績のまとめが表示されます。
- チャレンジの自己ベスト（誤差の合計）はブラウザに保存されます。
- チャレンジの結果は、結果画面の「Xで共有」「結果をコピー」（スマホでは「その他のアプリで共有」も）から共有できます。共有する文章には誤差の合計、1問ごとの成績（◎2%以内・○5%以内・△10%以内・×それ以上）、このページのリンクが入ります。
- 最低乱数のダメージが100％を超える問題では、100と入力してください。
- 簡単モードは数字キーの 1〜4 でも選べます。答えたあとは Enter で次の問題に進めます。

## 答え合わせの画面

回答すると、次の内容が表示されます。

- **残りHPバー**：最高乱数でも残るHPを色で、乱数によって変わる幅を斜線で、あなたの回答の位置を点線で表示します。
- **ダメージ・割合・タイプ相性・確定数**（確定1発、乱数2発 など）
- **計算の内訳**：実数値の計算式（能力補正＝性格の1.1倍・0.9倍を含む）、威力・こうげき・ぼうぎょにどの補正が掛かったか、基本ダメージの式、乱数16通りのダメージ、割合の計算

間違えたときは「計算の内訳」を開くと、どこで感覚がずれていたかを確認できます。

## どんな問題が出る？

| 項目 | 選ばれ方 |
|---|---|
| ポケモン | シングルバトルの使用率上位50種から、攻撃側と防御側を1匹ずつ選びます。守備的なポケモン（アーマーガア・ドヒドイデ・ピクシー）は攻撃側になりません。 |
| メガシンカ | メガストーンの所持率が60％を超えるポケモンはメガシンカ後の姿で、30〜60％のポケモンは通常とメガのどちらかで出題します。メガシンカZ・メガX/Yも同じ扱いで、所持率が一番高い姿が選ばれます。ガブリアスは通常（AS振り）とメガガブリアスＺ（CS振り）、ラグラージは通常（HB振り）とメガラグラージ（AS振り）のどちらか、カイリューはメガカイリューで固定です。 |
| 技 | 採用率15％以上の攻撃技から、相手に一番ダメージが出る技を使います。ただし振り方に合う技だけです（こうげきに振っていれば物理技、とくこうに振っていれば特殊技。両方またはどちらにも振っていなければ両方）。 |
| 特性・性格・能力ポイント | 実際の採用率に応じて選びます。採用率10％未満のものは出ません。メガシンカしたポケモンは、メガ後の戦い方に合う振り方（こうげき・とくこうの高い方に振ったもの）だけを選びます。性格は振り方に合わせて、特化しているステータスを上げるものだけを選びます（AS振りならこうげきかすばやさ、HB振りならぼうぎょが上がる性格）。 |
| 持ち物 | 火力が上がる持ち物を所持率10％以上で持つポケモンは、その所持率の確率で持っています（タイプ強化系1.2倍、いのちのたま1.3倍 など）。メガシンカしたポケモンは持ちません。 |
| 積み技 | りゅうのまい・つるぎのまい・わるだくみ・ちょうのまいを採用率15％以上で使うポケモンは、2回に1回の割合で1回使った状態で出題します。振り方に合う積み技（物理型ならこうげきが上がる技）だけを使います。積み技を使った状態では、出たターンにしか使えない技（であいがしら・ねこだまし）は使いません。 |
| 天候・フィールド | 攻撃側か防御側が天候やフィールドを起こす特性（ひでり、すなおこし、グラスメイカー など）を持っているときだけ発生します。両方が持っている場合は、後から発動した方で上書きされます。メガシンカしたポケモンが優先、どちらも同じ条件ならすばやさが遅い方が優先です（同速ならランダム）。どのポケモンの特性で発生したかは画面に表示されます。 |
| 難しさ | 最低乱数で105％を超える（明らかに一撃で倒せる）組み合わせは出題しません。 |

## 計算の前提

- レベル50、Pokémon Champions の能力ポイント制（1項目最大32、1ポイント＝実数値+1）で計算します。
- 防御側はHP満タン・状態異常なしです。急所には当たりません（必ず急所に当たる技を除く）。
- ギルガルドは、攻撃側のときはブレードフォルム、防御側のときはシールドフォルムの種族値で計算します。
- はたきおとすは、メガシンカしていない相手には道具を持っている前提で威力1.5倍、メガシンカした相手にはメガストーンを落とせないため威力65のまま計算します。
- いかくなど、場に出たときの能力ダウンは考えません。ばけのかわは剥がれている扱いです。
- 次の技は出題されません：威力が相手やHPで変わる技（くさむすび・ミラーコート・一撃必殺技など）、連続技（つららばり・ダブルウイング・スケイルショットなど）、こうげき以外のステータスで計算する技（ボディプレス・イカサマ）。

## データについて

- 使用率データ：[バトルデータベース チャンピオンズ](https://champs.pokedb.tokyo/) の **シーズンM-6（シングルバトル）確定データ**（期間 2026/9/9〜2026/10/7、2026-10-11取得）
- 掲載されている数値は取得時点のもので、自動では更新されません。

## 開発者向け

### ローカルで遊ぶ

- ブラウザ版：`docs/index.html` をブラウザで開きます（このファイル1つで動き、データも埋め込み済みです）。
- ターミナル版：`python3 main.py --mode easy`（`normal` / `challenge`、`--seed 1` で出題を固定）

### ファイル構成

| パス | 内容 |
|---|---|
| `main.py` | ダメージ計算・出題ロジック（Python）。**計算の基準はこのファイル** |
| `web/src/` | ブラウザ版のソース（`engine.js` は main.py の移植、`app.js` は画面、`index.html` はテンプレート） |
| `build_web.py` | データとソースを1ファイルにまとめて `docs/index.html` を作ります |
| `data/` | ポケモン・技・特性・持ち物・天候・フィールドのデータ（`data/schema/` に形式の定義） |
| `tools/build_usage_data.py` | 使用率データを取得し直して `data/pokemon.json` を作り直します |
| `test_main.py` / `test_web.py` | テスト（`test_web.py` はブラウザ版と main.py の計算結果が一致するかを確認） |
| `DESIGN.md` | 設計の詳細と、決めたことの経緯 |
| `REQUIREMENTS.md` | 最初の要件メモ |

### よく使うコマンド

```
python3 -m unittest test_main test_web         # テスト
python3 build_web.py                           # ブラウザ版（docs/index.html）を作り直す
python3 tools/build_usage_data.py --season 7   # 別シーズンのデータに更新（その後 build_web.py）
```

`data/` や `web/src/` を変更したら `python3 build_web.py` を実行してから commit・push してください。
GitHub Pages は `poke_damage` ブランチの `/docs` を公開しているので、push すると数分でサイトに反映されます。

データを取得し直すときは、取得元サイトに負荷をかけないよう、頻繁な実行は避けてください（取得したページは `.cache/` に保存され、2回目以降は再利用されます）。
